# Pokémon FireRed Dual Screen 0.1.1

This experimental Android update restores game audio and fixes the lower-screen
map and several menu/startup freezes.

## Changes

- Restore music, sound effects and Pokémon cries with the native MP2K driver,
  PCM/BDPCM mixer and CGB sound channels. Initialization no longer waits for
  unavailable GBA audio hardware.
- Preserve volume controls, normal-tempo fast-forward music, accelerated music,
  and audio pause/resume. Cry playback now reports completion correctly.
- Render FireRed's Kanto and Sevii Town Maps on the lower screen, with location
  markers and the correct map for the player's region.
- Fix Bag, TM Case and Berry Pouch initialization waiting indefinitely for
  graphics transfers.
- Prevent Pokémon Center entry/resume from starting unsupported GBA wireless
  hardware tasks. Multiplayer remains unsupported.
- Add regression tests for audio, maps, menu initialization and Pokémon Centers.

## Download and update

Download **Pokemon-FireRed-Dual-Screen-0.1.1.apk** and install it over the existing
release app. Back up your save first; do not uninstall or clear app data.

Package: `com.pokefirered.dualscreen`. Display version: **0.1.1**.
Android version code: **10401**. This is higher than local test builds through
0.1.4, so those builds can also update in place with their saves and settings.
The debug app remains separate.

The APK requires your own extracted **Pokémon FireRed Version (USA, Europe)
(Rev 1)** `.gba` file: 16 MiB, SHA-1
`dd5945db9b930750cb39d00c84da8571feebf417`. No full retail ROM is included or
provided. Matching ROM-data ranges are restored from the verified user ROM;
compiled code and unmatched upstream resources remain.

Use **SHA256SUMS.txt** to verify the downloaded APK. The standard 128 KiB save is
`Android/data/com.pokefirered.dualscreen/files/pokefirered.sav`.
See the [save guide](https://github.com/venom13/pokefirered-dualscreen#saves).

## Validation and limitations

The release build and packaging checks cover ROM-data reconstruction, native
loader error handling, package identity, signature and ZIP alignment. ARMv7
execution tests cover startup, all **91 music tracks and 255 effects**, normal
and reversed cries, concurrent playback, pause/resume, reset, volume and
2×/3×/4× resampling. Map, menu and Pokémon Center regression tests also pass.

The same game code was checked on **AYN Thor** in the local 0.1.4 build: cold
launch, Continue, quest-log return to gameplay, active speaker-routed stereo
audio and background/resume. Save and settings hashes remained unchanged.
This public build changes the version metadata; it is not a full-playthrough
or broad-device compatibility guarantee.

ARMv7 only; ARM64-only devices are unsupported. Widescreen remains experimental.
Link/wireless multiplayer, LeafGreen, other ROM revisions, translations and ROM
hacks are unsupported. Physical speaker output was not independently listened
to by the automated checks.
