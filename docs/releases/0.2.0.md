# Pokémon FireRed Dual Screen 0.2.0

This experimental Android update improves the lower-screen battle, Bag, and
party interfaces; fixes Summary and PC Operations crashes; and refreshes the
launcher icon.

## Changes

- Fix crashes in PC Operations, including Move Items and empty-cursor cases.
- Fix crashes when opening or closing a Pokémon Summary and when using the
  markings page.
- Start every new app session at normal game speed.
- Keep the battle prompt stable while entering and leaving FIGHT, BAG, and
  POKéMON, and show "What will {Pokémon} do?" while waiting for input.
- Remove brief stale battle and transition frames when returning from lower
  screen battle menus.
- Redesign FIGHT moves and the five exploration controls with a raised,
  three-dimensional button style.
- Replace the Bag tabs with category cards, show items on a separate scrolling
  screen, and provide an icon-based back control.
- Redesign party cards as full button surfaces and improve their spacing.
- Make party details close only through a dedicated back button; hide the five
  exploration controls while details are open and resize the cards to fit.
- Reduce the size of move effectiveness arrows.
- Replace the launcher artwork and add a circular adaptive icon without white
  corners.

## Download and update

Download **Pokemon-FireRed-Dual-Screen-0.2.0.apk** and install it over the
existing release app. Back up your save first; do not uninstall or clear app
data. The APK uses the same release signing key as earlier public versions.

Package: `com.pokefirered.dualscreen`. Display version: **0.2.0**.
Android version code: **10404**. The debug app and its saves remain separate.

Your own extracted **Pokémon FireRed Version (USA, Europe) (Rev 1)** `.gba` file
is required: 16 MiB, SHA-1 `dd5945db9b930750cb39d00c84da8571feebf417`.
No full retail ROM is included or provided. Matching ROM-data ranges are
restored from the verified user ROM; compiled code and unmatched upstream
resources remain.

Use **SHA256SUMS.txt** to verify the APK download. The standard 128 KiB save is
`Android/data/com.pokefirered.dualscreen/files/pokefirered.sav`.

## Validation and limitations

ROM-free regressions cover Summary opening and exit, Summary markings, storage
sprites, normal-speed startup, and the battle Bag, party, snapshots, switching,
and menu transitions. Android release compilation and the APK's package,
version, signature, alignment, and byte-exact ROM-restoration checks pass.

The signed release build was installed over 0.1.3 on an AYN Thor. Its save and
settings files remained byte-identical, cold launch completed, and Android's
crash buffer stayed clear. A complete playthrough and other devices have not
been validated. ARMv7 only;
ARM64-only devices are unsupported. Link/wireless multiplayer, LeafGreen, other
ROM revisions, translations, and ROM hacks are unsupported.
