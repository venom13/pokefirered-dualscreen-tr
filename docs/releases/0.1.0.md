# Pokémon FireRed Dual Screen 0.1.0

First experimental Android release of the native FireRed dual-screen port,
based on pret/pokefirered and Goldoire/pokeemerald-dualscreen.

## Download and install

1. Download **Pokemon-FireRed-Dual-Screen-0.1.0.apk** from this release.
2. Install it on a compatible dual-screen Android device with 32-bit ARM support.
3. Launch **Pokemon FireRed Dual Screen** and select your own extracted
   **Pokémon FireRed Version (USA, Europe) (Rev 1)** `.gba` file, not the ZIP.
4. Use the top display for gameplay and the bottom display for touch controls.

Required ROM: 16 MiB (16,777,216 bytes).
SHA-1: `dd5945db9b930750cb39d00c84da8571feebf417`.
The full retail ROM is not included and no ROM download is provided.
Matching ROM-data ranges are removed and restored from the verified user ROM;
compiled code and unmatched upstream resources remain.

## Included

- Native C / SDL2 gameplay with a FireRed-red dual-screen interface.
- Party, bag, trainer card, settings, and touch battle action/move menus.
- Current / maximum HP for both player and opponent Pokémon.
- Player EXP bar and within-level `Next Level: progress / required EXP` ratio.
- Roomier battle waiting cards without the loading-dot animation.
- Move details with separate name, type, and PP rows.
- White-accented launcher icon and lower-screen FireRed startup logo.
- Optional battle hints, top-screen battle menus, fast-forward and audio settings.
- FireRed intro, name entry, battle transition, save, and load compatibility fixes.
- ROM verification on each launch, checked asset restoration, and dedicated
  release signing.

## Saves and updates

Package: `com.pokefirered.dualscreen`; version: **0.1.0**; version code: **10000**.

This installs separately from the local debug app
(`com.pokefirered.dualscreen.debug`) and the Emerald app. It does not
automatically copy their saves or settings.

Standard 128 KiB battery save:
`Android/data/com.pokefirered.dualscreen/files/pokefirered.sav`.
Back up saves before importing or updating; emulator save states are unsupported.
See the [save guide](https://github.com/venom13/pokefirered-dualscreen#saves).

## Validation and known limitations

The underlying port's intro, name entry, first rival battle, save, Continue,
and quest-log return to gameplay were tested on AYN Thor during development.
For this release, the APK build, ROM-data reconstruction, native loader error
handling, signature, and ZIP alignment were checked locally.
**The newly signed ROM-gated APK has not yet received an on-device smoke test.**

This is not a complete-playthrough guarantee. ARMv7 only; ARM64-only devices
are unsupported. MAP rendering, multiplayer, LeafGreen, other ROM revisions,
translations, and ROM hacks are not supported. Widescreen remains experimental.

Use **SHA256SUMS.txt** to verify the downloaded APK. Report issues with the
device, Android version, reproduction steps, and a redacted crash log; never
attach ROMs, saves, or keys.
