# Pokémon FireRed Dual Screen 0.1.3

This experimental Android update fixes Pokémon Storage System crashes, restores
reliable save writes, and makes display settings and the in-game EXIT command
behave consistently on native Android devices.

## Changes

- Fix the crash when opening Someone's PC and moving the storage cursor without
  holding a Pokémon.
- Fix the crash after answering NO to "Continue BOX operations?". Storage now
  stops its VBlank callback before teardown and skips the rest of the frame once
  its state has been released.
- Fix save failures caused by a damaged or stale long-lived save path. Each
  commit rebuilds the Android external-storage filename before atomically
  replacing the live save.
- Make Widescreen default to OFF and remember the selected value on the device.
  OFF preserves the original 3:2 image with black side bars; ON stretches the
  complete game image across the upper display.
- Remove the unused Background setting from the lower-screen settings menu.
- Make EXIT in FireRed's own menu close the Android application cleanly.

## Download and update

Download **Pokemon-FireRed-Dual-Screen-0.1.3.apk** and install it over the
existing release app. Back up your save first; do not uninstall or clear app
data. The APK uses the same release signing key as earlier public versions.

Package: `com.pokefirered.dualscreen`. Display version: **0.1.3**.
Android version code: **10403**. The debug app and its saves remain separate.

Your own extracted **Pokémon FireRed Version (USA, Europe) (Rev 1)** `.gba` file
is required: 16 MiB, SHA-1 `dd5945db9b930750cb39d00c84da8571feebf417`.
No full retail ROM is included or provided. Matching ROM-data ranges are
restored from the verified user ROM; compiled code and unmatched upstream
resources remain.

Use **SHA256SUMS.txt** to verify the APK download. The standard 128 KiB save is
`Android/data/com.pokefirered.dualscreen/files/pokefirered.sav`.

## Validation and limitations

ROM-free native regressions cover save replacement and storage teardown,
including the reported NO response. The wider menu, battle, map, and storage
regression suite passes, as do Android release compilation and the APK's
package, version, signature, alignment, and byte-exact ROM-restoration checks.

The storage cursor crash was reproduced from an Android native crash trace and
fixed at the exact null access. The final release was checked on an AYN Thor.
A complete playthrough and other devices have not been validated. ARMv7 only;
ARM64-only devices are unsupported. Link/wireless multiplayer, LeafGreen, other
ROM revisions, translations, and ROM hacks are unsupported.
